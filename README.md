# Zoo MCP Server on Cloud Run

A secure MCP server built with FastMCP and deployed to Google Cloud Run (authentication required).

- **Cloud Run URL:** https://zoo-mcp-server-940016925775.us-west1.run.app
- **Tools:** `get_animals_by_species`, `get_animal_details`
- **Prompt:** `find` (use as `/zoo-remote:find lions` in Antigravity CLI)
- **Client:** Antigravity CLI (`agy`)
